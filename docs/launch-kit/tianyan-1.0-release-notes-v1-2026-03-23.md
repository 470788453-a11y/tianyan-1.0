## 一句话版本说明

`v1.0.0` 是天衍 1.0 的首个公开开源版本，重点是先把项目的最小骨架、基本说明和后续演进方向公开出来。

---

## Highlights

### 1. 首个公开版本发布
- 天衍 1.0 首次以 GitHub 开源仓库形式对外发布
- 从内部整理阶段进入“可公开查看、可持续迭代”的状态

### 2. 先开放基础骨架
- 1.0 优先公开项目结构、核心思路和最小入口
- 不追求一开始把所有能力一次性讲满

### 3. 强调任务推进与结果收口
- 项目关注的不只是“生成内容”
- 更关注任务如何推进、留痕、确认和收口

### 4. 为后续版本预留演进空间
- 先把 1.0 做成一个稳定起点
- 后续再逐步补齐样例、文档、验证和更多模块

## Known Limitations

当前版本的已知限制，建议写得直接一点：

### 1. 文档仍在继续整理
- 首版已经能看，但还不是最终形态
- 后续会继续补充更清晰的安装说明、样例和使用建议

### 2. 部分能力仍以骨架或预留接口为主
- 当前版本更强调结构清晰
- 某些模块可能还需要继续补细节

### 3. 对新用户仍有一定理解门槛
- 如果不了解项目背景，第一次阅读可能需要一点时间
- 后续会继续优化新手上手体验

### 4. 接口 / 目录 / 文档命名仍可能调整
- 1.0 是首个公开版本
- 后续小版本中仍可能有非破坏性整理和命名优化

## Upgrade / Getting Started

如果这是首个公开版本，没有升级历史，也可以写成：

### 第一次使用
1. 阅读 `README.md`
2. 按仓库真实命令完成依赖安装
3. 按 `.env.example` 或 `docs/` 完成最小配置
4. 从最小入口先跑通，再看扩展部分

### 如果你是后续补读用户
- 建议先看项目定位和版本边界
- 再看快速开始
- 最后看目录结构与 roadmap
